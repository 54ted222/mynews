[^dlp]: Data Loss Prevention，資料外洩防護。在 AI 場景指在 prompt、tool call、模型輸出等各層攔截敏感資料（PII、營業秘密、金融、健康）避免流出的 policy 檢查機制，可支援 shadow mode（觀察不阻擋）與逐步 rollout，是 SOC2 / ISO 27001 / HIPAA / GDPR 合規常見要求。

[^moe]: Mixture of Experts 稀疏專家混合架構。模型總參數雖大（T 級）但每次推論只啟用少數專家（active 幾十 B），推論成本遠低於同規模 dense 模型，是 2024 以來 max-class 開源模型（Kimi K3、Qwen3.8-Max、DeepSeek V3 等）主流架構。

[^contributor-tier]: Meta Muse 系列的優惠層級。用戶同意分享 code、prompt、trace 等資料回饋 Meta 用於訓練，就能拿到 ~90% API 定價折扣，本質為「以資料換價格」，主要目標客群為開源專案、side project、教學用途；企業與敏感 workload 通常不適用。

[^cms]: 華邦電（2344）Custom Memory Solution 客製化記憶體服務事業。替雲端服務商、AI 加速器客戶量身設計 DDR4 / DDR5 / HBM 變體與封裝規格，走高毛利 ASIC 記憶體路線；2024 起營收爆發，2025-2026 為華邦電營益率創歷史新高的主要推動力。
