[^hermes]: Hermes 是一款近年在資安圈流通的開源 AI agent 框架，能把多個 LLM 串成可自動偵察、決策、分工的協作團隊；原設計主要供研究與紅隊模擬使用，此次對台事件是首度被證實被改造為實戰入侵政府網路的工具。

[^openclaw]: OpenClaw 是與 Hermes 常搭配的開源 AI 攻擊自動化工具，專攻資訊蒐集、漏洞掃描與攻擊路徑的動態重評估；這次台灣事件顯示它可讓少量人力驅動 8 個並發 agent，接手過去需一整支紅隊才能完成的工作。

[^fhe]: FHE 全名 Fully Homomorphic Encryption（全同態加密），讓運算可直接在密文上進行，伺服器整個推理過程都看不到明文資料，是「私 AI 推理」的核心密碼學基礎；過去因效能太差難以量產，近年才逐漸接近可用門檻。

[^mlir]: MLIR (Multi-Level Intermediate Representation) 是 LLVM 專案下的多層中介表示框架，設計目的是讓機器碼、tensor 運算、加密運算等不同抽象層級共用同一套編譯器基礎設施；HEIR 即是在 MLIR 上實作 FHE 編譯後端。

[^rls]: RLS (Row Level Security) 是資料庫層級的橫向存取控制機制，Postgres、Supabase、Firestore 皆有對應實作；規則設定不完整就會出現本次 tl;dv 事件那類「已登入用戶可直接列到其他租戶資料」的漏洞。

[^acp]: ACP (Agent Client Protocol) 是 Devin/Windsurf 團隊推動的開源協定，目標是讓 AI coding agent 與 IDE 解耦；理論上未來可讓同一個 agent 在 VS Code、Cursor、Zed 等不同編輯器內互通運行，類似 LSP 之於語言伺服器。
