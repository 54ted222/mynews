[^arcadedev]: Arcade.dev 為一家主打 AI agent 工具平台的美國新創，提供 OAuth 授權、tool-calling 執行環境與 ToolBench 評測；2026 年 8 月 5 日收購 Smithery，成為後者的新母公司，接手 directory 運營並負責將原 proxy 功能於 10/31 退場。

[^promptfoo]: Promptfoo 為開源的 LLM 評測與 red-teaming CLI 工具，以 YAML 設定檔描述 test case、assertion 與 provider，支援 CI 整合與多模型比對；採本機執行 / 本機存檔的設計，OpenAI 官方 cookbook 將其列為 Evals 下線後的建議遷移目標之一。

[^langfuse]: Langfuse 為德國團隊開發的開源 LLM observability 平台，提供 tracing、prompt management、dataset 與 evaluation 功能，可自架或使用 Langfuse Cloud；v4 版主打 dataset / evaluator 效能大幅優化，官方 migration guide 將其對 OpenAI Evals 的匯入速度宣稱可達 165 倍。

[^agenthq]: Agent HQ 為 GitHub 於 2025 Universe 揭幕的 agent 開發平台，整合 Copilot、第三方 agent 執行環境、Mission Control 中控面板與 AGENTS.md 跨 repo 代理定義檔，供 Pro+ 與 Enterprise 訂戶使用；2026-02-04 把 Claude 與 Codex 併入 public preview，是 GitHub 當前「agentic development」敘事的主要落地載具。

[^mcp]: Model Context Protocol（MCP）為 Anthropic 2024 年 11 月開源的通訊協定，用來讓 LLM 應用與外部資料來源、工具伺服器之間以統一介面交換 context 與呼叫；採 client / server 架構，透過 stdio 或 Streamable HTTP 傳輸，目前被 Claude Code、Cursor、Codex 等多家客戶端廣泛採用。

[^safe]: SAFE（Simple Agreement for Future Equity）為 Y Combinator 2013 年設計的早期投資合約，投資人先付款、換得未來融資輪折讓轉換股權的權利，不計利息也不設到期日；因公允價值隨公司估值浮動，在 US GAAP 下常被歸類為負債，估值大漲時會產生大額 non-cash 虧損。

[^ga]: GA 為 General Availability 的縮寫，指軟體從 beta / preview / experimental / canary 等測試階段正式對所有使用者推出，並承諾向後相容與維運 SLA 的里程碑；相對於 canary，GA 版本通常意味 API 介面凍結、適合進 production，並具正式 pricing 與支援管道。

[^kimik25]: Kimi K2.5 為 Moonshot AI 於 2026 年中推出的中國大陸自研大型語言模型，主打長 context 與低成本 coding 推理；Cursor Composer 2.5 於 5 月 ship 時公開揭露其底層使用 Kimi K2.5，宣稱單位成本為 Opus 4.7 的約 1/10。

[^opus47]: Opus 4.7 為 Anthropic Claude 系列的高階模型層，定位於長 context、複雜推理與 coding agent 任務，為當前 Claude Code CLI 與 Claude Agent SDK 預設可選用的模型之一；相對於 Haiku 層走低延遲 / 低成本路線，Opus 層單價較高，常被引用為各家 coding agent 的成本對照基準。

[^sessionstore]: SessionStore 為 Claude Agent SDK 的跨 session 狀態儲存機制，讓 agent 可將上下文、subagent 進度與中間變數持久化至檔案或 KV store，再於下次 session 恢復；目前於 TypeScript SDK 以 alpha 階段提供，介面與序列化格式仍可能變動。

[^startupblink]: StartupBlink 為以色列顧問公司維護的全球新創生態系年度排名，依新創數量、品質（獨角獸、exit、投資額）與商業環境打分，涵蓋 100 多個國家與 1,000+ 城市，常被用作各國創業圈的國際基準。
