[^arcade]: Arcade.dev 是 Y Combinator 出身的 agent 工具平台，提供 MCP 相容的工具呼叫 SDK 與雲端 runtime，2026 年 8 月收購 Smithery；另自營 ToolBench 等 agent 工具評測基準，是近期 agent 生態圈較活躍的中介層玩家之一。

[^promptfoo]: Promptfoo 是以 YAML 設定為核心的開源 LLM 評估與紅隊測試工具，可在本地 CLI 執行、也能接進 CI pipeline；原為獨立專案，README 自述於 2025 年併入 OpenAI 旗下並維持 MIT 授權，常被拿來對比 Langfuse、Braintrust 等雲端 observability 平台。

[^safe]: SAFE 全名 Simple Agreement for Future Equity，由 Y Combinator 於 2013 年推出的早期募資合約；投資人以現金換取未來融資輪時依約定折扣轉為股權的權利，GAAP 下公允價值變動列為非現金損益，上市前 S-1 揭露常見此類科目。

[^pkce]: PKCE 全名 Proof Key for Code Exchange，是 OAuth 2.0 的防攔截擴充。client 在授權請求時產生 code verifier 與其雜湊後的 challenge，兌換 token 時再驗證兩者對應，用來擋 authorization code 攔截攻擊。OAuth 2.1 已將 PKCE 列為所有 public client 強制套用。

[^gntc]: GNTC 為 Dcard 於 2026 年成立的子品牌，名稱取自英文 agentic 的字根，寓意「代理化」。定位是 Dcard 首個對外的 B2B 業務單位，與原本 C 端社群／廣告業務分軌經營，目前揭露的產品線以企業內部流程自動化為主要切入點。
