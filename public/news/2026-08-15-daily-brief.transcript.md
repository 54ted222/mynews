今天想聊三件事：Claude Code 這一週連四版的重大更新、Alibaba 的 Qwen3.8-Max 意外真的上架但授權條款變了、還有 MSCI 台股權重罕見的「三升」怎麼直接影響週五的盤面。這三件事看起來領域完全不同，但都在告訴我們同一件事：對台灣一人公司或小團隊來說，這個週末有幾個必須做的動作，錯過就沒了。

先聊 Claude Code。Anthropic 從 8 月 12 號到 13 號，短短兩天內連續發了 v2.1.229、230、231、232 四個版本。最重要的是 232 這一版，它把「多 session 協同」正式變成一等公民的功能。過去你如果同時開好幾個 Claude Code 視窗，兩個 session 想互相說話，只能靠一些奇怪的變通做法。現在你可以直接寫 at 加 session 名字，用 SendMessage 就能跨 session 送訊；名字唯一的時候還不用再確認。搭配 subagent fork 現在也預設打開，意思是子代理會繼承主 session 的完整對話跟 prompt cache，側邊工作可以在背景跑，不會卡住主線。設定裡也新增了一個收件模式，可以決定其他 session 進來的訊息要接受、暫緩還是拒絕。GitLab 家族的六種 token 全部進了 secret redaction 名單；Windows 用戶那邊還修了一個 permission-bypass 的 critical 漏洞。所以如果你或你的團隊在 Windows 上跑 Claude Code，這是今天最該做的一件事：立刻 claude update，拉到 2.1.232。不過 subagent fork 預設開啟也有代價——prompt cache 會跟著 fork 過去，機密資訊有意外洩漏進子代理的風險，安全邊界要重新想過。

再來聊 Alibaba 的 Qwen3.8-Max。昨天的日報誤判說 Hugging Face 上還沒東西，實際上 8 月 12 號 Alibaba 就把這顆 2.4T 參數、95B 啟動的巨型 MoE 模型 push 上去了。vLLM 官方當天貼賀文，NVIDIA 官方部落格也馬上出了一篇在 GB300 NVL72 上部署的示範。架構本身很有意思——92 層、8192 隱藏維度、512 個專家，混合了 Gated DeltaNet 的線性 attention 跟一般的 gated attention；原生 262K token context，可以延伸到 1M。不過這裡有個重要的細節：授權條款不再是 Apache 2.0，改用 Alibaba 自己寫的 Qwen3.8-Max License。個人開發者或小型 SaaS 自架應該還是可以用，但如果你要做 hyperscale 商用產品或 MaaS 服務，就會踩到額外的授權門檻。所以對台灣做 self-host 的獨立開發者來說，第一件事不是先跑 benchmark，而是先讀 license，判斷你的商業模式會不會被卡到。這也是為什麼我覺得這週末寫一篇「Qwen3.8-Max 對比 Moonshot 的 Kimi K3、對比 Meta 的 Muse Glimmer 30B」的三軌 benchmark，同時談 license 相容性的中文首篇，是有時效優勢的窗口。

第三件事，也是本地資本市場最大的新聞——MSCI 台股權重「三升」。MSCI 每季都會做一次 Index Review，8 月 13 號台北時間清晨五點官方公告：全球市場指數從 3.08% 升到 3.13%、新興市場指數從 26.6% 升到 26.85%、亞洲除日本指數從 29.75% 升到 30.03%。三個都升，這在台股歷史上很罕見，大部分時候只會有一兩個升。更關鍵的是，台灣在新興市場指數的權重 26.63%，第一次超越所有其他市場，成為新興市場第一大市場。

但這裡有個蹺蹺板：台積電雖然還是新興市場第一大權重股，超過 15%，但這一次被調降了 0.79 個百分點，是所有台股裡調降最多的。反過來，南亞科被調升 0.49 個百分點，是單檔調升最多的。成分股六進六出——南亞科、華邦電、群聯、台燿、南電、景碩進來；鈊象、台泥、力旺、台企銀、康霈、陽明出去。另外還有 22 檔在外流通股數的調整。這些變動 8 月 31 號收盤才正式生效，但被動 ETF 的機械式買賣現在就會開始佈局。

簡單說，接下來兩週的資金劇本是：被動基金會從台積電流出，流入這六檔新增股。8 月 14 號週五的盤面已經在提前反映這件事——早盤加權大漲近 380 點衝上 46,400，尾盤台積電最後一筆殺到 2,395 元，收 -1.64%，把加權從紅拉到黑，收在 45,811，下跌 210 點。全天成交量 1 兆 645 億繼續放大；三大法人合計買超 508 億元，加碼很明顯，但敵不過台積電權重效應。軍工股獲利多大漲，記憶體、PCB、板廠這些新增股續強。

對客戶群裡有 PCB、板廠、IC 通路、記憶體上下游的一人公司來說，這個週末 8/16 到 8/17 是「MSCI 生效前 T-15 客戶 alignment」的窗口——Q3 到 Q4 的訂單可以提前談，加價空間大概 8% 到 15%。

其他今天值得知道的：Vercel 的 v0 API 8/5 正式 GA，最重要的新功能是 chats.createFromRepo，可以接既有 GitHub repo 或 ZIP，讓 hosting 平台可以包「AI 幫你改現有 codebase」的加值方案；xAI 的 Grok 4.6 在 Cursor 跟 Grok Build 上首週 2 倍用量，到本週日 8/17 到期，官方 eval 顯示在 GDPVal-AA v2、AA-Briefcase、Harvey LAB 三個 benchmark 領先，但 Fable 5 Max 在 coding 上還是贏；Cursor Composer 3 昨天有 teaser 說可能同日發表，結果 8/14 沒發，2026 下半年早期才是現實預期。半導體 232 第二階段的 chip proper 稅率，8 月中的決策窗仍然沒公告，多晶矽 15% 稅率則會在 12/4 生效，台灣因為最惠國待遇加上台美投資 MOU 的免稅配額，等於是零關稅通過。

重點是這個週末的行動清單：Windows 用戶今天就更新 Claude Code 到 2.1.232；讀 Qwen3.8-Max 的授權條款再決定要不要跑；週日 8/17 之前把 Grok 4.6 的兩倍免費用量跑滿五個代表工作流，其中至少一個要測 200K 以上 context 的價差 gotcha；如果客戶群有 PCB 或記憶體業者，把 T-15 客戶 alignment 排上議程。這幾個窗口都是這週限定的時效優勢，錯過就得等下一輪。
