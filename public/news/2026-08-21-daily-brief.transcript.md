今天想聊的，是台股這兩天坐了一趟雲霄飛車，還有下週那顆會牽動全場的財報，最後再帶幾個做 AI 的人現在該注意的事。

先講盤面。八月二十號週四，台股走了一個很漂亮的 V 型反彈，收在四萬四千九百三十三點，漲了兩百一十四點，漲幅百分之零點四八。重點不只是漲，而是外資翻多，買超三十七億。你要知道，前一天八月十九號才剛大跌五百八十九點，連季線都失守，市場一片哀嚎。結果不到四十八小時就止跌拉回，領漲的是記憶體那一群，華邦電、南亞科、旺宏。背後撐盤的有三件事：DRAM 現貨報價看漲、HBM 也就是高頻寬記憶體的需求外溢，加上供應商減產開始發酵。不過我要提醒，八月二十一號只是崩盤後 T 加一的反彈確認窗口，能不能站穩還要看量。而且下週三，八月二十六號 NVIDIA 財報出來之前，我不建議單邊樂觀，追高要小心。

再來就講這顆最大的變數，NVIDIA 的財報。它是台北時間八月二十七號早上、也就是美股八月二十六號盤後公布，現在距離大概還有五個交易日。市場共識營收落在九百二十億美元上下，年增大概百分之九十六，很誇張。公司自己給的財測是九百一十億，其中資料中心業務要超過兩百五十億，每股盈餘大概兩塊零六美元。但真正的看點不是這一季賺多少，而是它對下半年的展望，還有整個 AI 資本支出到底能不能持續。同一天台積電開盤的方向，也會直接決定這波記憶體反彈是真的還是曇花一現。

順著記憶體講，旺宏這次很亮眼。第二季每股賺三塊九一，創歷史新高，毛利率一口氣跳到百分之六十四點四。兩個引擎在推：一個是 NAND 跟 eMMC 供不應求，另一個是 NOR Flash 漲價。它還投了兩百二十億擴產，下半年就會開始貢獻。

接著換個角度，講幾個做開發、做 AI 的人現在該盯的訊號。第一個是 GitLens 十九版，八月十四號發布。它把那個 Commit Graph 重構成一個人跟 AI 一起工作的台面：可以追蹤 AI coding agent 在幹嘛、看 AI 幫你做的 code review、還能 AI 解衝突。最有意思的是可以針對每個功能分別選模型，寫 commit、做 review、解衝突各用不同的模型，而且第一次原生支援 GitHub 的堆疊式 PR。它點破一件事：當 AI 產碼變快之後，真正卡住的瓶頸已經不是寫，而是審查跟合併。

第二個要嚴肅一點。Anthropic 跟瑞士的 EPFL 在八月十八號展示了一種 AI agent 蠕蟲。簡單說，惡意的 payload 可以透過那種「可以被編輯的 system prompt 檔案」，從一個 agent 傳染到下一個 agent。同一時間，MLflow、FUXA 這些開源平台也爆漏洞被利用。所以如果你在做 AI agent 或 MCP，這是明確警訊，趕快去補檔案權限的邊界，別讓 prompt 檔隨便被寫。

第三個講一下 Cursor。它的 Composer 3，代號 Vega，現在還在放風聲，沒正式推出。傳聞有六種變體、四段推理層級、一點五兆參數，效能大概介於 GPT-5.4 到 5.5 之間，但成本更低。我的建議就是觀望，別為了一個還沒發布的模型去改你的工作流，等它真的上線再說。

最後補兩個比較實務的。如果你在想台灣的 SaaS 題目，這幾天其實冒出三個方向：一個是把台股崩盤到反彈這種雙敘事做成 dashboard；一個是幫團隊做 AI agent 的安全稽核，包成 audit pack；還有一個是幫 AI 團隊做那種每個功能分別選模的成本稽核顧問。另外，台灣的新創補助像 SBIR、SIIR、TIIP，很適合補在做完 MVP 到接到第一批付費之間那段資金缺口，尤其 SIIR 對 AI SaaS 算友善，可以去研究。

所以重點是，短線台股靠記憶體撐出反彈，但真正的裁判是下週的 NVIDIA 財報，反彈能不能延續全看它；而做 AI 的人這週該做的，不是追新模型，是先把 agent 的檔案權限守好。
