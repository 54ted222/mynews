今天想聊的主軸只有一條線：AI 記憶體超級循環，這回真的有硬證據了。搭配這一天 AI 生態同步爆出的三件大事，剛好可以看出「上游硬體吃 AI capex、下游模型跟工具搶開發者」是同一個故事的一體兩面。

先講記憶體這一條。八月六號華邦電開了第二季法說，結果是這樣：合併營收五百九十八億台幣，季增百分之五十六、年增百分之一百八十四。毛利率衝到百分之六十六點二，這是華邦電歷史新高。每股盈餘五塊四，光是上半年就賺了七塊六五。這些數字放在半導體公司裡都算相當漂亮，但真正的重點在細節。他們的記憶體事業季增百分之七十三，其中「客製化記憶體」，也就是專門為特定客戶——大部分是 AI 加速器的大廠——量身打造的那一塊，季增百分之七十八、年增超過百分之四百。產能利用率百分之百，滿載。管理層在法說上還丟出一句話：明年，也就是 2027 的記憶體供貨會比今年更緊，而且長期採購合約的覆蓋率還在往上加。

華邦電這一場如果只是單點事件，可能還會有人說「一家公司好而已」。但同一天，南亞科公告七月營收，四百三十八點六八億台幣，月增百分之四十九、年增百分之七百一十九，而且已經連續八個月創新高。一到七月累計營收年增百分之六百六十。DDR4 第三季合約價，法人估還會繼續漲。

兩支公司在同一天丟出這種級別的數字，等於是台灣記憶體大廠第一次在同一個月，同時給出「AI 記憶體超級循環進入實際入帳階段」的硬證據，不是預期、不是展望，而是已經認列的營收。這對做 AI 供應鏈儀錶板或客戶談判 SOP 的獨立開發者是很直接的訊號：以前寫給客戶的話術如果還停在「rotation 觀望中」，現在可以直接改成「Q3、Q4 訂單能見度延伸到 2027」，而且有兩支上市公司的財報數字可以背書。

不過這裡有個要提醒的副作用：當上游 CMS 跟 DDR4 都在漲、長約覆蓋率都在提高，代表大廠鎖了未來的定價權，也就是說中小型 SaaS 或硬體整合商想用「便宜的記憶體」壓成本這條路，未來十二個月會越來越難走。要嘛把漲價 pass-through 給客戶，要嘛自己吞毛利。這是一個需要提早跟客戶對齊的財務話題。

同一天大盤本身是小跌收盤，加權指數收在四萬四千三百九十六點七，跌了兩百多點，成交量從前一天的兆位縮到九千四百億。台積電個股收兩千三百六十五、跌一點六六個百分點。但記憶體那兩支——南亞科跟華邦電——收在漲停。這個組合意義很清楚：大盤在獲利了結，資金在旋轉，而下一站就是記憶體。

好，記憶體這條講完了，來聊同一天 AI 生態爆出的三件事。

第一件，xAI 的 Grok 4.6 今天正式發布。這是 Musk 七月底預告的模型，一點五兆參數的第九代基座沒有換掉，但用了改進版的監督式微調加上強化學習硬拉表現，目標對標 Anthropic 的 Opus 4.8 跟 Moonshot 的 Kimi K3。分發通路跟 Grok 4.5 一樣，xAI API、Grok app、grok.com、還有 X 的 Premium+ 訂閱都可以用。價格官方還沒公布，但因為前代 Grok 4.5 是輸入兩塊、輸出六塊美金一百萬個 token，市場預期 4.6 應該同層或略低。二點一兆的 Grok 4.7 也預告幾週內跟進。

這件事對做「LLM 路由器」的獨立開發者是個關鍵時點。所謂 LLM 路由器，簡單說就是在 Claude、GPT、Gemini、Grok、Kimi 這些不同的模型供應者之間，依成本、速度、任務類型自動幫你挑最合適的那一個。過去三週已經接連冒出 Anthropic Opus 4.1 硬下架、Meta Muse Code 上線、Anthropic Sonnet 5 促銷倒數這一連串大事，現在再加上 Grok 4.6，等於八月到九月變成一個路由器 A/B 測試的極限窗口。誰能在中文圈搶先做出「五個模型並排跑同一批中文 workload」的對照表，這一波流量就是他的。

第二件事更有意思：Meta 在八月五號到六號正式發表 Muse Code，這是一個以終端機為主的 AI coding agent，一條指令啟動、能協調多個子代理派任務，backing 的模型是同時發表的 Muse Spark 1.2。這個模型跟 agent 是共同訓練的，還內建專用的 code-management harness。定價本身照 Muse Spark 1.1 走，輸入一塊二五、輸出四塊二五美金一百萬個 token。但真正殺招是他們同時開了一個叫「contributor tier」的檔次：只要你同意把你的 code、prompt、trace 資料分享出去，超過百分之九十的折扣——換算下來大概輸入零點一二、輸出零點四二，等於免費送你用。

這是第一次有科技巨頭用「資料換價格」把 CLI coding agent 直接打成免費層。對本來一年在 Claude Code 或 Codex CLI 上花兩千到一萬五美金的獨立開發者衝擊很大。你的開源專案、side project、教學專案，理論上都可以直接搬過去用 contributor tier，一年 API 帳單從兩千掉到一百五。當然代價是你的 code 跟 prompt 會被 Meta 拿去訓練。什麼專案可以搬、什麼專案不行，這裡有很明確的決策樹可以做，也是這一波的內容機會。

第三件事，Anthropic 八月五號向 Business Insider 確認正在自建 silicon 團隊。Careers 頁面上開了一整批晶片設計職缺，年薪三十二萬到四十八萬五千美金，涵蓋前端設計、pre-silicon 驗證、physical design、DFT、類比與混合訊號、封裝的訊號與電源完整性。技術領導 Clive Chan 是前 OpenAI 硬體團隊二號員工，再之前在特斯拉的 Dojo。TechCrunch 揭露他們在跟三星電子談製造夥伴關係。策略定位很直接：自己設計晶片、專門針對 Claude 的 attention 運算特性做客製化，目標是把 Claude 的推理成本砍半。

Attention 是什麼？簡單說就是 Transformer 模型內部拿來計算「哪些 token 應該關注哪些 token」的核心運算，是 LLM 推理成本跟延遲的最大瓶頸。Anthropic 決定為這個運算專門刻一顆晶片，等於是走 Google TPU 的路線，但選擇三星代工而不是台積電。這條新聞對台灣供應鏈短期不是壞消息也不是好消息：台積電短期吃不到這一塊，但封裝、silicon photonics、DFT 工具、silicon IP 這些台廠有機會直接跟 Anthropic 的 silicon 團隊接觸做業務開發。對用 Anthropic API 的 SaaS 團隊，這是一個十二到十八個月後 API 定價可能下修的前瞻訊號，可以放進客戶的中期規劃裡。

把這幾條線串起來看：上游是台灣記憶體大廠端出硬證據、AI capex 進入實際入帳；中游是 hyperscaler 一邊自建晶片壓推理成本、一邊補貼開發者搶生態；下游是模型層一週三個 tick、路由器 A/B 進入極限窗。這三層其實是同一個超級循環的不同面向，只是節奏不一樣。

重點是：如果你在做 AI 供應鏈的儀錶板、路由器 audit、或者 CLI 工具堆疊的內容，這個週末——八月八號到八月十號——是你能同時吃到四條首篇窗的最集中時段。中文圈目前這些題目的供給幾乎都是零，先發者拿到的位置會很不一樣。今天就這樣。
