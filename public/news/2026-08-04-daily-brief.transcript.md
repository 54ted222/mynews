今天想聊三件事，把它們串起來看，你會發現八月上半這兩週，剛好卡在一個很微妙的窗口。

第一件事，是 MCP 的 2026-07-28 正式版終於出來了。技術細節聽起來很枯燥，但影響非常大。Anthropic 跟 MCP steering committee 在七月二十八號公告了 spec 最終版，最關鍵的一個改動，就是把整個協定的核心從「雙向、有狀態」改成「請求對回應、無狀態」。

翻譯成白話文是這樣。以前你要開一個 MCP server，接到 Claude 或 ChatGPT 這種 AI 助手裡，你的 server 必須整天開著、跟客戶端維持長連線，通常要用 WebSocket 或 SSE 這種不會掛掉的技術。這代表你至少要租一台 VPS，一個月大概二十到五十塊美金，還要自己顧 process supervisor、顧重啟。對獨立開發者來說，是很煩的門檻。

現在 stateless 化之後，MCP server 可以直接部署在 Cloudflare Workers、Vercel Edge、AWS Lambda 這種 serverless 平台上。成本從一個月二十到五十塊，掉到一個月五塊美金 flat，流量小的話幾乎免費。所以，如果你手上已經有一個台灣本土的垂直 SaaS，例如電商 POS、診所排程、律所文件管理、補習班 CRM，你原本就有一套 REST API，現在把它包成 MCP server 上架 registry，未來七到十四天是一個蠻明顯的 first-mover 窗口。中文的教學文章、七天 sprint 的模板，現在幾乎沒人寫。

再來聊第二件事，DeepSeek V4-Flash-0731 的公開 beta，也是七月三十一號上線。定價是每一百萬個 token 輸入零點一四美金、輸出零點二八美金，快取後的輸入更是只要三厘美金，等於打了九八折。Terminal Bench 2.1 跑到八十二點七分，在同價位裡遠遠領先。

但這裡有個很重要的但書。Artificial Analysis 實測發現，這顆模型很囉嗦，同一個任務會生成兩億一千萬個 token，其他模型的中位數只有六千兩百萬，也就是它會多產生三點四倍的 token。你不能只看紙面單價，要把囉嗦係數乘進去，才是真實成本。

所以現在的 low-tier 選項可以這樣排：agentic coding 跟 terminal 自動化這類任務，V4-Flash 是新的首選；一般聊天、摘要、翻譯，Luna 反而更划算，因為它不會多吐三倍輸出。這個對照表對台灣做 LLM router 顧問的一人公司，可以直接開 audit sprint 去接案。

不過別忘了 Sonnet 5 的促銷價八月三十一號到期。目前輸入兩塊、輸出十塊美金，到期後變三塊跟十五塊，名目漲百分之五十，加上 tokenizer 對中文的編碼會多兩成到三成五 token，實質漲幅可能到五成以上。八月中前是最後轉單窗，該遷 batch 就遷 batch、該做快取就做快取。

第三件事，也是今天我覺得對台灣 SaaS 生態最有意思的變化，就是台北市青年局在七月二十九號公告、八月一號正式開跑的「青年 AI 工具補助計畫」。這是台灣有史以來第一次，政府直接補助民眾的 SaaS 訂閱費。

規則大概是這樣。設籍北市六個月以上、十八到三十五歲、大專院校在學或應屆、修過 AI 相關課程或參加過青年局培訓的青年，一般人一年最多補助四千塊台幣，中低收跟低收戶最多八千塊。補助期是八月一號到十月三十一號，最晚十一月十號前送件。先自己訂閱、再拿發票申請，一年一次、一次最多兩項。

補助白名單有 ChatGPT、Gemini、Claude、Canva、Adobe、Midjourney、Copilot、NotebookLM、Notion AI、Grammarly、Speak，總共十一種主流 AI 工具。而且很明確地寫明排除中國大陸開發的軟體，像 CapCut、美圖秀秀、WHEE 都不能報。

這件事對台灣一人 SaaS 生態有兩層意義。第一，如果你自己是本土 SaaS 提供者、沒進到白名單，你在台北青年這個客群的 CAC 拉力會被政府補助擠掉一塊，得另找槓桿。第二，反過來說，如果你做的是 AI 培訓、家教平台、或是白名單裡某個工具的台灣代理，這三個月就是很明確的聯合行銷窗口。組合可以是：培訓機構提供先修學分讓青年符合門檻、代辦訂閱、再綁 affiliate 追蹤。

中文的一站式 SOP 現在市場上大多還停在新聞層，INSIDE、104、BlockTempo、華視都寫了，但沒人把「三步驟走完、白名單對照上限、申請文件範本、排除清單警示」整合成可以直接執行的文件。今天二十點前如果能發第一篇，加上一段十分鐘內的 Loom 教學，再私訊五家培訓機構或白名單代理，蠻有機會拿到三到五個 audit lead。

把這三件事串起來看，你會發現一個節奏。上游，MCP stateless 把 dev 基建門檻壓低，讓一人 SaaS 開 MCP integration 變得可行。中游，V4-Flash 把 agentic coding 的成本再往下砍一刀。下游，台北市補助直接把台灣本地終端用戶的 SaaS 付費意願往上抬。這三段的窗口，剛好都落在八月上半。

順帶提兩個變數要盯。台股昨天八月三號週一收在四萬三千三百八十六點，大盤加了兩百六十六點，但台積電卻回調百分之二點二七、跌到兩千三百七十塊，沒守住週五的漲停價。大盤跟台積電走勢開始背離，今天早上八點半開盤是判斷「反彈延續還是個股分化擴散」的關鍵訊號。另一個是刑事局八月要上路的詐騙統計改版，把詐欺分成電信網路、非電信網路、假性財產犯罪三類。165 打詐儀錶板的資料要全部重新校準，做防詐 SaaS 的獨立開發者八月中前要趕快幫客戶更新 dashboard rubric，不然客戶會問「怎麼數字突然掉這麼多」。

重點是，八月上半這個窗口不算長，但幾條線同時開，不用每條都追，挑一條你手上資源最接近的下手就好。中文首篇、七天 sprint、audit 諮詢，這三種產品形態現在都能對應到很清楚的需求。祝各位開工愉快，明天見。
