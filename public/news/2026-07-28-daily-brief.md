[^mcp]: Model Context Protocol，Anthropic 於 2024 年 11 月開源的協定，讓 LLM 與外部工具、資料源、UI 以標準化 host / client / server 三角色互動；跨模型通用，目前 Anthropic、Cursor、Microsoft、Okta 均已支援。2026-07-28 final spec 為 launch 以來最大改版，主軸為 stateless 化、OAuth 2.1 認證對齊、EMA extension 穩定，並保證 12 個月 deprecation window。

[^section-232]: 美國 1962 年貿易擴張法第 232 條款，總統可依「國家安全」理由對特定進口貨物加徵關稅或設配額，不需經國會同意。本輪針對半導體與 AI 晶片，2026-01 已對 H200 / MI325X 等先進 AI 晶片課 25%，7 月底將公告成熟製程調查結果與最終稅率；台灣希望爭取到「台美 ART」同等條件。

[^kimi-k3]: 中國 Moonshot AI 於 2026-07-27 在 Hugging Face 開源的旗艦模型，共 2.8T 參數的 sparse Mixture-of-Experts（896 位專家、每 token 啟動 16 位）+ 1M-token context + Kimi Delta Attention + Stable LatentMoE。以 Modified MIT 授權允許商用，但訓練資料與訓練程式碼不公開；hosted API $3/$15 per Mtok。

[^opus5]: Anthropic Claude Opus 5，2026-07-24 launch 的旗艦 agentic 模型，取代 Opus 4.8 成為 Claude Max 預設；提供 low / medium / high / xhigh / max 五段 effort toggle、1M context、$5/$25 per Mtok（同 Opus 4.8、Fable 5 半價），Claude API 與 Claude Code 預設 effort 為 high。

[^sonnet5]: Anthropic Claude Sonnet 5，2026-06-30 上線，接替 Sonnet 4.6 成為 Claude Free / Pro 預設模型；定位為 Opus 5 之下 40-60% 較便宜的日常 tier，部分 case 表現接近 Opus 4.8。$2/$10 introductory 定價於 8/31 UTC 過期後恢復 $3/$15 標準價；tokenizer 較 Sonnet 4.6 encode 1.0-1.35x 更多 tokens，實質成本上漲 20-35%。

[^rfc-9728]: OAuth 2.0 Protected Resource Metadata，2025 年通過的 IETF 標準（RFC 9728），讓 client 可透過 well-known URI 查詢 resource server 所指定的 authorization server 與 scope，免除硬編碼設定。MCP 2026-07-28 spec 將此列為 server MUST 實作項目，作為 agent 認證的基礎。

[^ema]: Enterprise-Managed Authorization extension，MCP 2026-07-28 spec 附掛的企業級認證擴充。允許企業 IT 集中管理 agent 對 remote MCP server 的存取範圍、對接 WorkOS / Auth0 / Okta 等 OIDC provider，並支援管理主控台統一撤銷 token。屬 spec 的 stable extension，Anthropic、Microsoft、Okta 為首批採用者。

[^tpv]: Total Payment Volume，指某段期間內經由該支付平台清算的交易總額，PayPal、Block、Adyen 等公司每季財報必揭項目，用來反映平台交易量與市佔。TPV 本身不是收入，需再乘上平台的 take rate（手續費率）才等於營收，因此 TPV 高成長並不必然代表利潤同步擴張。

[^mor]: Merchant of Record，法律意義上的銷售主體。Lemon Squeezy、Paddle 等 MoR 平台以自身名義開立發票、代收全球消費稅（VAT / GST / 銷售稅）與處理退款、chargeback，賣家只需拿到淨額入帳；相對地 Stripe Connect、PayPal Business 屬 payment processor，稅務與合規仍由賣家自行負擔。

[^sparse-moe]: Sparse Mixture-of-Experts，只在推論時啟動部分子網路的模型架構。整體權重雖大（例如 Kimi K3 為 2.8T），但每個 token 僅走少數 expert（K3 為 896 位中啟動 16 位），實際 FLOPs 與延遲遠低於同尺寸 dense 模型，適合以較少 GPU 服務超大參數；代價是 memory footprint 仍需容納完整權重。
