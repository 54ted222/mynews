[^cursor-composer-3-teased]: Cursor 自研 coding 模型系列的下一代（前兩代 Composer 2／2.5 以 Moonshot Kimi K2.5 為 base），代號 Vega。外流檔案顯示為 1.5T 參數、含 Fast／Medium／High／XHigh 四段 reasoning 與 6 種變體，訓練於 xAI 的 SpaceX Colossus cluster。2026-08-13 曾在後台被短暫觀察到，官方公告時點尚未公布。

[^devin-desktop-aug-update]: Cognition 於 2026-06-02 將 Windsurf 更名為 Devin Desktop 後首波大版本更新。Devin Local 以 Rust 全面改寫、token 使用效率提升約 30%，並補上 subagents、Agent Client Protocol、Spaces、Agent Command Center、ACU usage 顯示、faster MCP startup、Windows setup 修復、subagent 預設模型、commit message attribution 與編輯器開啟檔案感知等能力。

[^msci-em-index]: MSCI Emerging Markets Index，涵蓋約 24 個新興經濟體大中型股，是全球被動 EM ETF 與追蹤基金最主要的 benchmark。「三大最大新增」是 MSCI 官方在季度指數審視發布時額外點名的名單，意味該檔在被動買盤流入強度上顯著高於一般新增，對短線成交量與資金結構影響較大。

[^acp]: Agent Client Protocol，Cognition 隨 Devin Desktop 開源的 agent 與 editor 溝通協定，設計目標類似 LSP 之於語言伺服器：讓任一相容 agent 能在任一相容 editor 中執行。若 Cursor、Claude Code 等主流 IDE／CLI 未來也採納，coding agent 與 editor 生態將可解耦、方便跨產品切換與並存。
