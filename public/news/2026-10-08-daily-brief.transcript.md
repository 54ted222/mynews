今天想聊的是 2026 年 10 月 8 日週四，也就是第四季第八個工作日，中秋連假後完整工作週的第四天。這一天我自己盯的訊號不少，但如果要挑一條主線貫穿，我會這樣講：這一天其實是一個「遷移急件堆疊」的日子，從境外的 OpenAI 平台生命週期，到國內的政策資金池細節落地，再到 dev tool 的免費倒數，全部都壓在同一個禮拜要做決策，所以本週四是 outbound 的衝量末日，週五十月九日就是一堆事情的分水嶺。

先從最急的事情講起，就是 OpenAI 的 Agent Builder 要下線了。這件事其實六月三號 OpenAI 就官方宣布過，但真正影響台灣團隊的日期有兩個，第一個是本月底十月三十一號，Evals 這個評測工具會轉成唯讀，距離今天還有二十三天；第二個是十一月三十號，Agent Builder 整個停役，距離今天五十三天。長期取代路徑是 Agents SDK，也就是 code-first 的那條，ChatKit 還可以繼續商用，無程式碼需求的話官方建議改走 ChatGPT Workspace Agents。對台灣有在用 Agent Builder 搭多 agent workflow 的團隊，本週就要開始遷移，不要拖到十一月底變急件。

接著一個結構性的 context，是 OpenAI 的 Sora。Sora 的 Web 跟 App 其實四月二十六號就停了，Sora API 也在九月二十四號停役，距離今天十四天，Sora-2、Sora-2-Pro、Videos API 全部棄用，而且官方沒給一比一的替代。有引述說日成本一百萬美金是停役的主因。所以如果你的 SaaS 有包含 AI 影片這條垂直，就要重估 provider 的依賴，Veo 3、Runway、Luma、Kling、Pika 這些要多軸切。

再來講台灣政策端的兩個大錨。第一個是國發基金的天使投資方案，細節這次落地得很清楚，累計核准兩百九十九家新創，核准投資四十三點零五億，誘發天使共同挹注三十三點七億，帶動民間資金一共一百八十點二七億。重點調整有幾個，單一公司的投資上限從兩千萬拉到一億，整整五倍；申請新創設立年限從五年放寬到八年；整體額度從五十億倍增到一百億；受理延長到二零三零年底；創業大聯盟競賽初賽有兩千八百零五組報名。簡單說，單一公司一億這個上限，是二零二六年台灣最大的政策額度調整，可以直接變成 outbound 的新量化錨。

第二個是龔明鑫九月三十號加碼宣示，未來八年要投一千億算力經費協助中小微企業，二零二七年起每年再加兩百五十億，涵蓋一百萬家中小微企業導入 AI。經濟部產業競爭力輔導團從三月底的兩千零五十八家，擴大到現在一萬三千家，等於六點三倍。台灣中小微企業母體大概一百七十多萬家，申請案通過率六成。這一組數字就是給 indie SaaS 跟 SI 顧問做 outbound contact base 用的新錨。

工具層的話，Cognition 的 SWE-2 免費期進入最後兩天，十月十號之後 Devin Pro 月費二十美金、Max 兩百美金、Teams 基本八十再加每席四十。更麻煩的是 SWE-2 本身十月十號之後的 pricing，Cognition 還沒公布。所以本週四跟週五是台灣 freelancer 跟 indie 做 shadow eval 的最後兩天，週五十月九號是最後決策日，要在 Devin、Codex SDK、Cursor Composer 2.5、Claude Code Sonnet 5.5、Replit Agent 3 這五軸裡做選擇。

然後有一個今天要特別更正的時程，就是 iPhone Duo。先前連續好幾天在流傳的「十月九號早上十一點台灣大哥大預約」其實是錯的，那個時間點是九月十一號當週 iPhone 18 Pro 的預約時程被誤植。正確的 iPhone Duo 時程是十月十六號晚上八點，台灣大哥大 myfone 的單機預購，距離今天八天；開賣是十月二十三號，距離十五天。中華電信則是十月二十三號早上八點全台近五百間據點開賣。往後計日錨就以十月十六號為準。顏色比例是星白六成、夜空四成，近百萬預約，首年預估一千萬台，但是 Foxconn 下修到六百萬，這個落差本身就是分岔訊號。

最後是台積電 Q3 財報，十月十五號週三公布，距離今天七天，安靜期十月五號到十四號正在進行中第四天。共識每股盈餘七十六點零九元新台幣，年增百分之五十三。Q3 營收共識被上修到四百五十四億美金，全年二零二六年營收上修到一千七百一十六億美金。CoWoS 的緊俏延伸到二零二七年之後，2nm 商業量產屬於早期階段，爬坡會帶來三到四個百分點的毛利率稀釋。這些就是蘋概股在財報前重新定價的素材。

重點是，這一天的本質是「本週四 outbound 衝量末日、週五做決策、本月底是第一道遷移死線」三件事疊在一起。該清點的 Agent Builder workflow 要清點，該做的 SWE-2 shadow eval 剩最後兩天，該卡位的國發基金一億上限跟一千億算力 contact base 現在就要開始跑。十月三十一號 Evals 讀寫轉唯讀，十一月四號 Haiku 5.5 跨 Q1 分水嶺，十一月十號 TiBOOST 決賽，十一月三十號 Agent Builder 整個下線，接下來的 trigger 鏈就是這樣排下來的，今天如果不動，急件就會疊到月底。
