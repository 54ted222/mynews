今天想聊 2026 年 8 月 5 號的創業情報，一次五到八分鐘、幫你把今天最急的幾件事看過一輪，尤其是給台灣做一人 SaaS 或小團隊 AI 產品的你。

先講最急的：Anthropic 的 Claude Opus 4.1 今天 UTC 硬性下架。這件事 Anthropic 早在 6 月 5 號就公告了、六十天倒數，今天到期。也就是說，你如果還有任何腳本、cron、router 的 fallback，或是舊 code path 在呼叫 claude-opus-4-1-20250805 這個 model id，從今天起 API 會直接回錯誤 500。這是一人 SaaS 這個月最現實的事故：昨天還好好的 AI 功能，今天壞掉、客戶開 support ticket 進來。官方建議的遷移路徑是切到 Opus 5 或 Opus 4.8，價格都是每百萬 token 五塊美金進、二十五塊美金出，跟 Opus 4.5 以來同價、沒有漲。Opus 5 在 ARC-AGI-3 這個 benchmark 從前一波的 8% 直接跳到 30% 出頭，terminal、browser 的 autonomous 能力大幅前進，通常建議直接切過去。搭配這件事，Sonnet 5 的五折 promo 8 月 31 號到期、剩 26 天，等於這個月中之前是 Anthropic bill 治理的雙重時效窗。今天先做的事很清楚：先 grep 你整份 codebase 找 claude-opus-4-1 這個字串、把 router 的 health check 加上、Sentry 或 Datadog 也加 alert，然後準備 A/B 切模型。

接下來聊昨天 Cloudflare 丟出的新東西，其實這件事跟第一件是一組的。8 月 4 號 Cloudflare 官宣「Cloudflare Wallets」加一個新的付款原語叫 cloudflare.pay。簡單說，就是給部署在 Cloudflare 上的 AI agent 一個穩定的身份、外加在人類設定的額度內線上刷卡的能力，還有完整的 audit trail。以前 agent 要付錢，你得自己接 Stripe、跟客戶要授權、還要自建額度控制，現在這些變成平台層原生。同一天 Cloudflare Agents SDK v0.20 也把 7 月 28 號才頒布的 MCP 新版 spec 做成 native，Workers 可以直接 serve tools、prompts、resources、elicitation，不需要再自己扛 MCP transport session 或 Durable Object。從 spec 頒布到 platform native 只花七天。這對台灣做垂直 SaaS 的一人團隊代表兩件事一起打通：你可以用七天把自家 REST API 包成 MCP server 上 Cloudflare Workers、順便把 agent 收款 lane 也接進去，等於把「agent 幫使用者採購、續費、marketplace 下單」的整條路徑都串完。過去這條路要接 Stripe、要自建額度、要對帳，現在平台層一次到位。7 到 14 天內上 Wallets alpha 就是 first-mover 窗。

再來聊歐盟的合規、這對台灣有歐盟客戶的 SaaS 很重要。EU AI Act 的 Article 50 條款 8 月 2 號正式生效，到今天 T+3。這條規範四類要求：直接跟人互動的 AI 系統要揭示「你正在跟 AI 講話」；生成合成內容的系統要加 machine-readable marker、也就是水印或 provenance；情緒辨識跟生物特徵分類要明示告知；deepfake 要標示。違反最高 1500 萬歐元或全球年營收 3%，取高。而且注意，沒有 grandfathering、之前已經上市的系統也一體適用，不能說「我早就上線就不算」。對台灣 5 到 20 人的 SaaS 團隊、只要你有歐盟客戶、又用了 chatbot 客服、生成式文案、AI 廣告、voice agent，你就已經觸線了。這禮拜可以做的最小動作：先盤點一下自家產品哪些介面會被 Article 50 打到，把「這是 AI」的揭示 UX 先補上，生成內容的水印方案 C2PA 或 SynthID 挑一個 pilot 導入。C2PA 是 Adobe、Microsoft、BBC 主導的 metadata 標準，SynthID 則是 Google DeepMind 的隱形浮水印，兩個都在歐盟認可名單。

台灣本地看兩件事，這兩件其實是連動的。第一，昨天 8 月 4 號台股千點震盪，加權收 43,360 點、只跌 25 點幾乎持平，但台積電收 2,320、跌 2.11%、失守 10 日線。日內高低差超過一千點、成交量破一兆。這代表資金明確從台積電 rotation 出來、跑進二線 AI 供應鏈。第二件連動的事：南亞科、華邦電、力積電三檔昨天同場漲停，大摩把目標價一次拉到南亞科 550、華邦電 222、力積電 111，樂觀情境南亞科上看 1160。催化是 DDR4 下半年缺 20% 以上，加上力積電獨家供 Intel EMIB-T 這個先進封裝技術的矽電容、良率已經逼近 9 成、記憶體代工價 7 月起漲 45%。DRAM 合約價 Q3 預估再漲 20 到 25%、Q4 再 15 到 20%、2027 上半年缺得最兇。這對做 AI SaaS 的意義：模型 vendor 的 GPU 記憶體成本會連動漲，8 到 10 月開始你可能會被動吃到 API 漲價、gross margin 要提早準備下修或轉嫁，不然就是把使用量分 tier。

最後 AI 模型面。阿里巴巴 8 月 3 號發表 Qwen3.8-Max，2.4 兆參數 MoE、95B active、1M context，PaperBench 拿到 93 分，領先 GPT-5.6 Sol 的 90.5、Fable 5 的 88.8、Opus 4.8 的 80.3。DashScope API 定價每百萬 token 進 2 美元、出 6 美元，比 Opus 5 便宜六成。更關鍵的是 8 月 10 號前後 weights 會上 Hugging Face 跟 ModelScope、用 Apache 2.0 授權，是阿里第一個開源的 Max class 模型。加上 Kimi K3 已經 7 月 27 號開源、雖然 license 比較窄，台灣現在有兩個 max class 開源選項可以自架、資料留在本地，對 data-residency 敏感的客戶是明確賣點。搭配鴻海亞灣超算商轉五天，租 GPU 對比自架的 breakeven 值得重算一次。自架路徑通常靠 vLLM 或 SGLang 這些推論引擎起。
