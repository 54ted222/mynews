今天想聊三件事，都是 10/10 國慶 Saturday 的 trigger。你如果有在追我這週的 brief 就會知道，我前面連續幾天都誤判了一條新聞，所以第一件事我要先道歉再更正，然後兩件還沒放掉的事情才接上。

第一條，Claude Haiku 5.5。我前面連續三、四天都寫說，這個模型大概要到十月下旬才會落地，依據的是 DataLearner 的估期。結果今天早上重新爬了一輪國際 AI 媒體，才發現這模型早在十月七號就已經正式釋出了。模型 ID 叫 claude-haiku-5-5，AWS、GCP、Azure 三家雲都已經上架。所以我前陣子寫的「未落地」是錯的，今天的 brief 第一件事就是把它改回「已釋出」，而且狀態從「等待期」切回「shadow eval 期」。

那這條新聞為什麼值得花力氣處理？因為它的定價非常猛。輸入每百萬 token 一毛錢、輸出五毛，條件是 context 在十萬 token 以內。平均比 Haiku 4.5 便宜大概七成五，是這一兩年來同一品牌最大一次單代降價。然後 Haiku 系列第一次支援所謂的 effort levels，簡單說，就是你可以在 API 裡面指定模型要「想多深」。低 effort 回答快但思慮淺、高 effort 慢但完整。這個以前只有 Opus 跟 Sonnet 有。

對我這種把 LLM 當產品核心的獨立開發者來說，意義很直接。日報轉譯、分類標籤、多 agent 架構裡面的子任務角色，這些高頻但不複雜的工作，單位成本可能一次砍四分之三。所以今天的高優先行動就是啟動 shadow eval。挑一個現在產品裡還在用 Opus 或 Sonnet 的子任務，準備大概二十條 sample，兩邊各跑一次，記下成本、品質、延遲三個維度，明天就能拿到對比表。

不過有一個 caveat 要先放進去。有一個叫 Terminal-Bench 4.0 的 benchmark，Haiku 5.5 只拿到 39.2 分，Sonnet 5.5 是 70.6。白話文：如果你的 agent 是在跑複雜的、多步驟的程式開發流程，Haiku 5.5 落差太多，不能無腦換。它適合的區間還是摘要、分類、短步驟的工具呼叫這類任務。

好，第一條講完。再來第二條，是 SWE-2 的 pricing cliff。Cognition 的 SWE-2，就是 Devin 背後那個模型，一個月的免費試用期今天結束。10/11 開始，你要繼續用就得訂閱 Devin Pro 二十塊、Max 兩百、或者 Teams 基礎八十再加每個 seat 四十。重點是，per-token 單價 Cognition 到現在還沒公告，所以你如果今天不做決策、放著自動續訂，進入下週就會在不知道後續成本的情況下開始付費。

所以今天最後決策日的意思是這樣：如果你過去三十天真的有用到 Devin，而且 PR 通過率有六成以上，續 Pro 二十塊很划算，一天不到一塊美金；但如果你是上個月開了帳號然後只試了兩三次，那現在要果斷關掉。中間還有一條路——如果你今天還有時間，就把過去這陣子累積但不急的任務一次灌進去跑完，把免費額度用到盡再退。這部分大概抓三十分鐘就夠做決定，不要再往後拖。

第三條，連假 bench 窗口。今天 10/10 是 Saturday、明天禮拜天、下週一有沒有補假看公司，但基本上這是台灣工程師跟 indie hacker 一年裡少數幾段「不會被打擾也不會打擾別人」的連續時段。我覺得這個窗口的用法不是放鬆，而是蓋章——把本週想做但沒做完的事做完、把下週的 pitch 定稿先備好。

具體建議三件事。第一，剛剛講的 Haiku 5.5 shadow eval，六十分鐘可以起手。第二，如果你的主線在用 Vercel AI SDK，趁連假跑一次 v6 到 v7 的 codemod 升級，breaking change 其實不多，大概一個小時可以搞定，但你平日絕對擠不出這塊整段時間。第三，如果下週要 pitch 或 demo，把三件事列出來——落地頁、demo video、pricing page——各花多少小時排清楚，不然連假結束你會發現自己只是刷了三天 Twitter。

然後有兩個觀察點順便提一下，影響的是下週。TSMC 10/15 法說，Q3 財報市場 consensus 營收 458 億美金，重點不是數字本身，是會不會把 2027 的 tone 調緊、CapEx 上緣有沒有再往上拉。因為如果拉了，Groq、Together、Fireworks 這些 inference infra 的降價空間就會被壓住，你的 fallback 模型選擇要重新想一輪。另一個是 Anthropic IPO，Financial Times 傳十月目標是 2 兆美金估值，如果真的在這個月啟動路演，Claude API 的 pre-IPO 彈性定價可能有最後一波議價空間，重度用戶可以嘗試鎖多年合約。

重點是，10/10 這天雖然是國慶放假，但從 AI 工具的角度看，它其實是一個 trigger 多到爆的本週蓋章日。Haiku 5.5 要重跑 shadow eval、SWE-2 要做最後續訂決策、連假三天要把下週 pitch 的三件事排進去。這三件事如果你今天完成兩件、連假結束前完成第三件，就會比上週多一個身位。好，今天就到這裡，週一見。
