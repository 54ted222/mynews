[^mcp]: Model Context Protocol，Anthropic 於 2024 年 11 月開源的協定，讓 LLM 與外部工具、資料源、UI 以標準化 host / client / server 三角色互動；跨模型通用，目前 Anthropic、Cursor、多家 IDE 均已支援。2026-07-28 spec 為 launch 以來最大改版，主軸為 stateless 化與 OAuth 2.1 認證對齊。

[^section-232]: 美國 1962 年貿易擴張法第 232 條款，總統可依「國家安全」理由對特定進口貨物加徵關稅或設配額，不需經國會同意。本輪針對半導體與 AI 晶片，2026-01 已對 H200 / MI325X 等先進 AI 晶片課 25%，7 月底將公告成熟製程調查結果與最終稅率。

[^sonnet5]: Anthropic Claude Sonnet 5，2026-06-30 上線，接替 Sonnet 4.6 成為 Claude Free / Pro 預設模型；定位為 Opus 5 之下 40-60% 較便宜的日常 tier，部分 case 表現接近 Opus 4.8。$2/$10 introductory 定價於 8/31 UTC 過期後恢復 $3/$15 標準價。

[^moe]: Mixture of Experts，模型內建多個「專家」子網路，每個 token 只啟動其中一小部分，可在相對低算力下執行極大參數模型；訓練與 serving 成本遠低於同尺寸 dense 模型。Kimi K3 共 2.8T 參數、896 位專家，每個 token 只啟動其中 16 位。

[^rfc-9728]: OAuth 2.0 Protected Resource Metadata，2025 年通過的 IETF 標準（RFC 9728），讓 client 可透過 well-known URI 查詢 resource server 所指定的 authorization server 與 scope，免除硬編碼設定。MCP 2026-07-28 spec 將此列為 server MUST 實作項目，作為 agent 認證的基礎。
