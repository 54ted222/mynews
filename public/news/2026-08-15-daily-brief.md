[^cc-v2-1-232]: Claude Code v2.1.232 是 Anthropic 於 2026 年 8/13 發布的 Claude Code CLI 版本。此版本把「多 session 協同」正式 first-class 化：subagent fork（inherits full conversation + prompt cache）default on、`@sessionName` cross-session mentions 讓 Claude 可用 SendMessage 直接跨 session 發訊、`/config` 加「Dialog expiry」與「Messages from your other sessions」（accept/hold/refuse）控制其他 session 進來的訊息；同時把 GitLab token 家族（`glrt-` / `gloas-` / `glptt-` / `glagent-` / `glimt-` / `glsoat-`）全 family 進 secret redaction；並修 Windows permission-bypass critical 漏洞。Windows 用戶尤其須立即 `claude update`。

[^qwen38-max-live]: Qwen3.8-2.4T-A95B（原名 Qwen3.8-Max）是 Alibaba 於 2026 年 8/12 於 Hugging Face 上架的 max-class 開源大語言模型，也是 Alibaba 首度把 Qwen-Max class 模型公開釋出 weights。技術規格為 2.4T total params / 95B active / 92 layers / 8192 hidden / 512 experts，架構混合線性 attention（Gated DeltaNet）與 gated attention，262K token 原生 context（可延至 1M），開源版為 text-only 且只能 thinking mode，vLLM 與 SGLang day-0 支援。授權條款改用自家 Qwen3.8-Max License（非 Apache 2.0），對 hyperscale 商用與 MaaS 服務有額外的 authorization threshold，一般個人與小型 self-host 應可用但需細讀。

[^vercel-v0-api-ga]: Vercel v0 API 是 Vercel 旗下 AI 應用建構工具 v0 的 headless API 版本，2026 年 8/5 正式在 api.v0.dev/v2 GA。與傳統只能從單一 prompt 生成新專案不同，v0 API 提供 `chats.createFromRepo` 端點可接受既有 GitHub repository 或 ZIP archive，讓 hosting / SaaS 業者能把「用 AI 幫改客戶現有 codebase」包成加值功能。安全設計上 Preview tokens 為 short-lived、官方建議 API keys 只放 server 端並用 intermediate proxy 控管瀏覽器端行為。

[^msci]: MSCI 為 Morgan Stanley Capital International（摩根士丹利資本國際）指數公司；旗下全球市場 (ACWI)、新興市場 (EM)、亞洲除日本等系列指數為全球被動 ETF 追蹤基準。每季由官方公布 Index Review 結果調整成分股與權重，變動生效日前後常觸發被動基金機械式買賣壓，是台股短線重要的事件驅動因子。

[^mfn]: MFN 為 Most-Favored-Nation（最惠國待遇），WTO 貿易架構下的核心原則之一：一國給予任何貿易夥伴的最優惠關稅待遇必須平等適用於所有其他 WTO 成員。美國 232 條款下若列入 MFN 名單，該國該項商品即可比照最優稅率處理，本次台灣多晶矽即以此疊加台美投資 MOU 免稅配額而免去 15% 稅率。

[^vllm]: vLLM 是起源於 UC Berkeley 的開源 LLM 推理引擎，以 PagedAttention 技術大幅提升 GPU 記憶體利用率與批次吞吐，是自架大型開源模型（Qwen、Llama、Kimi 等）最主流的 serving 選擇之一。「day-0 支援」指模型發表當天 vLLM 就有對應 kernel / config 可跑，是判斷新模型能否被 self-host 生態立即採用的關鍵訊號。

[^gb300-nvl72]: GB300 NVL72 是 NVIDIA 於 Blackwell Ultra 世代推出的 rack-scale AI 系統：單一機櫃以 NVLink switch 串接 72 顆 B300 GPU 對應 36 顆 Grace CPU，讓整個 rack 在延遲與頻寬上可被視為單一大型加速器，是 2026 年 hyperscale 廠訓練與推理 trillion-parameter MoE 模型的旗艦硬體平台。

[^kimi-k3]: Kimi K3 是中國新創 Moonshot AI 於 2026 年 7/27 以 Apache 2.0 授權開源的 2.8T MoE 大模型，1M token context、API 定價每百萬 token $3 / $15 加 $0.30 cache，公開權重約 1.4TB；vLLM 於 8/3 加入 Kimi Delta Attention 支援 self-host，是本篇拿來對照 Qwen3.8-Max license 商用門檻的「純開源」替代品。
