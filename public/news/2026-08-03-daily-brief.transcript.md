今天想聊三件對台灣一人公司、五到二十人小團隊本週動作影響最直接的事。第一件是今天早上八點半台股開盤，第二件是七月一日剛落地的 GSMA Open Gateway 三大電信 API，第三件是 Cursor Composer 3 從 Kimi K2.5 換自主 pretrain 之後，中文效果可能出現的變化。三條線今天做完決定，會直接影響你這一週要發哪一篇、要打給哪個客戶。

先講台股。上週五七月三十一日，加權指數收 43,119 點，單日漲了 3,186 點，是史上最大單日收盤漲點。台積電漲停收 2,425、電子類漲九個百分點、三大法人合計買超 846 億。可是七月月線其實還是收黑、跌了三千多點。單日暴漲跟月線下跌這個矛盾，就要看今天早上開盤怎麼走。

我建議盯三條線。開高兩百點以上，就是反彈延續，上週被延後的客戶案子可以主動發信；平盤附近開，就是政策落地觀察期，不用急；開低兩百點以上，代表要逢高獲利了結，你上週被延後的客戶會繼續延後，力氣放在下一輪 pipeline。台積電 2,425 有沒有守住，是最關鍵的單一訊號，破了其他都要打折看。

所以如果你手上有做客戶談判 SOP、或做 AI 供應鏈儀表板，今天早上八點到九點半這一個半小時是這週最短的極限窗。發一篇「七三一暴漲 T+2 加 8/3 開盤決策樹」的中文短文，五個 CEO 主動 DM，一天可以拿三到六個急件 audit 案，一個一萬二到三萬，總量四萬到十四萬。

第二件，是我覺得對本週動作影響最大、但被討論最少的一條，就是 GSMA Open Gateway 在台灣真的落地了。七月一日，中華電信、台灣大哥大、遠傳，跟臺灣網路認證公司 TWCA，一起啟動新一代 MID Plus 行動身分認證服務。他們共同規劃十四支 Open API、首波先開四支，你的 SaaS 只要接 TWCA 一次，就可以同時拿到三家電信的驗證能力。

這件事重要在哪。台灣 SME 銀行、信合社、保險、電商、遊戲平台，用戶身分驗證絕大多數還是靠 SMS OTP，也就是簡訊驗證碼。可是簡訊 OTP 現在被詐騙集團打得很慘，SIM Swap 詐騙，就是把你的門號盜過去接收簡訊，2025 到 2026 年台灣估算損失三十到八十億。

Open Gateway 這一套 API，把「這個號碼最近有沒有被換過 SIM 卡」、「這支門號的實名認證」、「這支手機大致位置」這幾個訊號，從電信端直接推到金融或電商後台。過去要跟三家電信分別談合約，現在 TWCA 當統一介面，一支 API 打通。

那機會在哪。中文快訊、可執行 SOP、「三週把 SME 銀行從 SMS OTP 遷到 MID+」這種落地手冊，現在是零供給。如果你今天下午到晚上有時間，發一篇中文首篇，配十五分鐘 Loom 示範 auth flow、個資法 checklist、定價談判籌碼，五個 SME 銀行或保險 CIO 主動 DM，一個 audit 一萬五到四萬，抓三到六個客戶，可以做到六萬到二十四萬。

不過有個變數要先講清楚。TWCA 是這條產業鏈的統一介接平台，也就是 gatekeeper。API 對 SME 的實際定價、每分鐘可以打幾次、有沒有沙盒環境，這些官方還沒正式公告。所以你跟 SME 客戶談的時候，要老實說「定價這一段我幫你去 TWCA 問，不要現在承諾單價」。這反而是誠實的優勢，因為現在市場上根本沒有第二個中文顧問講得清楚這一段。

第三條主線技術一點，是 Cursor Composer 3，代號 Vega。簡單說，Cursor 過去兩代的 Composer 2 跟 2.5，其實是拿中國 Moonshot 的 Kimi K2.5 當 base、再做繼續訓練。Kimi K2.5 中文語料密度高、tokenizer 對中文友善，所以 Cursor 過去對中文 comment、中文變數名、中英混雜 code base 表現都算不錯。

可是 Composer 3 這一代 Cursor 決定自己從零 pretrain，1.5 兆參數，跑在 SpaceX 的 Colossus 超算，超過十萬顆 H100。這是 Cursor 第一次進到 Anthropic、OpenAI、xAI 那一層。同一天 SpaceX 用六百億美元全股票併購了 Anysphere 也就是 Cursor 母公司。

對台灣的意義是什麼。Composer 3 訓練資料是 xAI 集群為主、英文為主，所以中文 comment 品質、中文變數建議、繁體 docstring 自然度，很可能會有可觀察的 regression。也就是說，你過去覺得 Cursor 中文效果不錯，是因為它站在 Kimi 肩膀上。Composer 3 上線之後這個優勢會消失。

建議做兩件事。第一，先不要急著切 Composer 3 quota，等公開 GA 之後再校準。第二，如果你團隊有中英混雜 code base、有寫繁中 docstring 的專案，這一週設計一個小 A/B benchmark，把 Composer 2.5 跟 Composer 3 中文輸出擺一起比，記錄差異。這個 benchmark 未來就是你跟客戶談「AI IDE 遷移 audit」最強的敲門磚。

重點是這樣。今天早上八點半台股開盤是 T+0 極限窗，決定這週客戶會不會恢復簽單。GSMA Open Gateway MID+ 是這個月最被低估、對台灣 SME SaaS 最實在的機會，敢寫中文首篇 SOP，audit 案就會來。Cursor Composer 3 中文效果是三週後才會爆的變數，這一週就開始做 A/B 記錄，等 GA 出來你就是第一個有數據講話的人。三件事都不用等，今天就可以動。
