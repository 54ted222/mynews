[^approve-for-me]: OpenAI 於本輪 Codex CLI 更新新增的命令列旗標。過去 agent 遇到需人工確認的動作（寫檔、執行 shell、呼叫 MCP tool）會停下來等 y/N，加了這個 flag 之後就自動代為批准、不再彈 prompt。適合 CI / headless 場景，代價是同時把 prompt injection 與側通道洩漏的「爆炸半徑」放到最大，是否開要當成安全決策而非便利設定。

[^section232]: 美國《1962 年貿易擴張法》第 232 條，授權總統以「國家安全」為由對特定進口品加徵關稅或設配額，程序上不需經國會同意。Trump 任內密集援引（鋼、鋁、汽車、半導體），本次多晶矽案再度沿用；市場普遍視為第二階段「半導體晶片本體」232 稅率的前導訊號，因此該案 8 月中決策窗至今未公告是持續關注焦點。

[^dynamo]: NVIDIA 於 2025 年開源的分散式 AI 推論框架，主打 disaggregated inference——把 prefill 與 decode 拆到不同 GPU 節點，以提升大型 MoE 模型與長 context 場景的吞吐與成本效率。定位對標 vLLM、TGI、TensorRT-LLM，但更貼合 GPU cluster scale-out，本次 CVE-2026-24254 CVSS 9.8 是該框架首個 critical 級漏洞。

[^kimi-k3]: 中國 Moonshot AI 於 2026-07-16 公告、7/27 開源的 2.8T 參數混合注意力（Kimi Delta Attention + Attention Residuals）大模型，1M-token context 原生視覺理解，Apache 2.0 授權。它是首個真正商用可 self-host 的 max-class 開源模型（Qwen3.8-Max 承諾但尚未上架），前端 coding benchmark 首度贏過閉源 Claude / GPT，配合 vLLM / NVIDIA / AMD day-zero 推論支援。

[^msci]: MSCI Inc.（前身 Morgan Stanley Capital International）是全球主要股票指數編製商，其新興市場、亞洲、全球等系列指數為多數被動 ETF 與主動基金追蹤標的。每年 2、5、8、11 月做季度調整（Quarterly Index Review），決定成分股增刪與權重變動；公告後被動基金需依規調整持倉，常在生效日前後帶動個股短期資金流入或流出。

[^mcp]: Model Context Protocol，Anthropic 提出、後由 Linux Foundation 底下 Agentic AI Foundation 接手治理的開放協定。定義 AI agent 與外部工具、資料源之間的統一介接方式，讓同一個 client（Claude Code、Codex CLI 等）能透過統一 spec 呼叫任意 MCP server 提供的能力。2026-07-28 spec 轉 stateless core、加上 OAuth 2.1 授權，為現階段 agent 生態通用底層。
