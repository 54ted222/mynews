先講最重要的：台股。週一那天大家記憶猶新，加權崩了兩千零三十點，史上第三大跌點；結果昨天，也就是七月二十九日，我們在 brief 裡面把它定義成一個十字路口，講白了就是「要嘛二次探底、要嘛政策落地反彈」，兩條路只能選一條。今天七月三十日結果出來了，加權指數收在四萬六千一百二十五點九一，漲了一千一百二十六點，幅度百分之二點五，正式收復四萬六這個心理關卡。盤中最高一度衝上一千六百一十一點，這是史上第四大盤中漲點。台積電呢，收在兩千四百一十元，漲四十塊，不過盤中一度衝上加一百零五塊，尾盤漲勢急縮到只剩一半，這個要留意。所以簡單說，兩天下來淨變化其實還是負九百點左右，但是型態上已經完成了 W 底測試，昨天講的十字路口，今天答案揭曉：走第二條路，政策落地反彈確認。

那這代表什麼？如果你在做 AI 供應鏈的儀表板產品，之前的觸發線是「四萬點守不守得住」，現在整個要翻過來，變成「四萬八前波高當壓力測試」，台積電要看兩千五百這個前波高有沒有辦法挑戰。族群輪動也要監控，從電子雙雄、ABF 載板、IC 設計，一路到矽智財，四段 sector rotation 要一段一段追。如果你做的是一人公司 SOP 陪跑，昨天你賣的是盤前急件劇本，今天要立刻切換節奏，改推「反彈後客戶談判恢復 SOP」的 second wave 陪跑，一單抓一萬到兩萬五千塊，接三到五個客戶，因為客戶預算解凍的窗口就是這兩三天。

不過這裡有個變數：明天七月三十一日就是預期的兩三二條款半導體最終稅率公告日。台灣已經在二月十三日簽了台美對等貿易協定 ART，拿到百分之十五的最惠國待遇，還有產能兩點五倍配額；日韓、歐盟現在也都拿到百分之十五。所以明天要看的是先進製程稅率、成熟製程稅率、還有台灣 ART 有沒有實際生效。如果先進製程壓到百分之五以下，那就是台積電族群買點；如果成熟製程被砸到百分之十五以上，那 IC 設計、封測、半導體設備這條線就要進二十四小時 audit。你今天如果只做反彈慶祝，明天就會措手不及，記得把明天的鬧鐘設好。

第二條線，AI Wave Show 二零二六，今天正式開展，七月三十日到八月一日，世貿一館，三天。兩百家廠商、五十場論壇、三大展區分別是 Agent、Edge、還有國際級主題館。開展時間是早上九點半到下午五點半，免費預登。今年首度參展的名單很值得看：AMD、威聯通、凌群、緯謙、台灣是德、意藍、美商鄧白氏、資誠、中華電信、華擎，然後最關鍵的：日本軟銀 SoftBank 首次參展。這個對想做台日連線的獨立開發者是很明確的訊號。所以你如果有時間，今天九點半以前準備好三個場景的 talking points，一個給開發者、一個給業務主管、一個給投資人，每個場景大概準備五句對話，然後帶著 QR code 或 NFC 掃碼工具進場。有 booth 的客戶可以做首日陪跑，一單一萬五到四萬五；想接 SoftBank 亞太連線 sprint 的，價格可以拉到三萬到八萬。展只有三天，今明後三個時窗都很短，別拖。

第三條線，這條特別急。Anthropic 的 Opus 5 是七月二十四日發布的，到今天 T 加六。中文的第一篇完整 SOP 到現在還是零供給，這是一個真空狀態。今天七月三十日，就是中文首篇 SOP 的最後極限日，明天 T 加七之後窗口就會關掉，題目會被別人搶走或是失去新鮮度。你要打的三個層次是：Opus 5 的五段 effort toggle，從 low、medium、high、xhigh 到 max，怎麼配；Kimi K3 標準價每百萬 token 三塊、輸出十五塊，怎麼當 fallback；還有 Anthropic Sonnet 5 promo 現在是每百萬 token 兩塊、輸出十塊，但是八月三十一日就要過期漲回三塊十五塊，還有三十二天倒數。這三個 tier 一起排出來，就是台灣五到二十人團隊 monthly bill 治理的核心表格。

再補兩個維度：Opus 5 的 hallucination rate 在 AA-Omniscience 這個 benchmark 上上升了十四個百分點，來到百分之五十，這對做醫療、金融、法遵的團隊是 quality gate 疑慮。第二個維度是延遲，max effort 首個 token 要吐出來平均六十八秒，中位數也才兩點八一秒，所以 effort tier 選擇跟延遲代價要放在一起衡量。今天早上八點以前把這篇發出去，加一支十分鐘的 Loom 錄影，七天內接三到五個 audit 客戶，一單兩萬到五萬。真的沒時間就抓這個。

第四條線是 AI IDE 三方分歧。今天有個關鍵事件：Cognition 這家公司，估值兩百六十億美金、年化 ARR 大概四點九二億美金，收購了 Windsurf 之後 ARR 直接翻倍。他們在六月二日完成 rebrand，Windsurf 變成 Devin Desktop，IDE 底層改成 Devin agent，走的是 autonomy 路線，也就是「派任務走開再回來看結果」。同一個時間點，Cursor 這邊 Composer 二點五已經打到 Opus 4.7 級別，但只要十分之一的成本；下一代 Composer 3 代號 Vega，四段 reasoning modes、六個內部變體、一點五兆參數，預計下半年推出。再看 GitHub Copilot，四百七十萬付費訂閱、Fortune 100 有九成在用、Business 每席十九美金、Enterprise 每席三十九美金、flex billing 六月一日上線。加上 Anthropic 官方的 Claude Code，這就是四方分歧。

台灣五到二十人團隊的選型糾結就在這裡：想要自主派任務的走 Devin Desktop、要精細人機協作的走 Cursor、要企業級 PR 整合的走 Copilot、要 Anthropic 原生 effort tier 的走 Claude Code。中文首篇的四方選型表現在也是零供給，今天中午十二點以前發出去就是 first mover，一單一萬五到四萬。這篇跟 Opus 5 那篇可以互補，早上八點發 Opus 5、中午十二點發 IDE 選型，一個上午打完兩篇 first mover。

所以重點是：今天早上八點以前把 Opus 5 中文首篇 SOP 發出去搶最後極限日、中午十二點以前把 Devin Desktop 對 Cursor 對 Copilot 對 Claude Code 四方選型表發出去、上午盤前接三到五家「反彈後客戶談判恢復」second wave 陪跑、上午九點半到下午五點半排時間進 AI Wave Show 首日展場收 leads 順便對接 SoftBank、然後全日盯明天七月三十一日兩三二條款結果的儀表板觸發線。四條線串起來，一個獨立開發者今天大概可以打出三十萬到八十萬台幣的 potential，別浪費這一天。
