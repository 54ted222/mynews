[^jackson-hole]: Jackson Hole 為每年 8 月由堪薩斯城 Fed 主辦的經濟政策研討會，於美國懷俄明州同名小鎮舉行。因議程含 Fed 主席主題演講，被市場視為央行對未來貨幣政策訊號的年度公開窗，機構常據此校準未來 6-12 個月的政策路徑，是全球最受關注的央行行事曆事件之一。

[^cme-fedwatch]: CME FedWatch 為芝加哥商業交易所（CME Group）依 Fed Funds Futures 期貨價格反推、即時公布的 FOMC 各次會議升／降息機率工具。由於機率來自市場資金實際下注的期貨價位，被視為政策預期的主流量化指標，比主觀評論更能反映機構配置變化。

[^s-1]: S-1 為美國證管會（SEC）Registration Statement 的表格代號，是公司在美國首次公開發行（IPO）前必須公開遞交的完整招股書草案，內容涵蓋財務、風險因素、募資用途與經營現況。公開遞交後才進入正式路演與定價流程，是 IPO 流程中的關鍵里程碑。

[^managed-agents]: Managed Agents 為 Anthropic Developer Platform 提供的 agent 治理服務，讓企業用戶集中控管 Claude 驅動的 agent 執行環境，涵蓋 session 花費上限、次要 advisor 模型、推論地區指定與 skill 檔來源等治理維度。與自建 agent 框架相比，優勢在合規基線與可觀察性。

[^restricted-mode]: Restricted mode 為 Claude Code 於 v2.1.248 引入的安全執行模式，依白名單阻擋高風險 shell、檔案系統與網路操作，避免 agent 在自動化情境中誤刪檔案或外送敏感資料。適合金融、政府、醫療等合規敏感情境部署，是企業級 agent 上線的關鍵安全開關。
